# IELTS Reading Assistant

Software Engineering course project scaffold.

## Project Structure

- `frontend/`: User interface.
- `backend/`: API and application services.
- `analysis/vocabulary/`: Vocabulary analysis.
- `analysis/sentences/`: Complex sentence analysis.
- `analysis/error-review/`: Answer review and weakness analysis.
- `analysis/recommendations/`: Improvement recommendations.
- `tests/`: Unit, integration, and evaluation tests.
- `docs/`: Proposal, requirements, design, and project management.

## Branches

| Branch | Purpose |
| --- | --- |
| `main` | Stable project baseline and releases. |
| `develop` | Integration of reviewed work. |
| `feature/frontend` | User interface development. |
| `feature/backend` | API and data management. |
| `feature/reading-analysis` | Vocabulary and sentence analysis. |
| `feature/error-review` | Error analysis and improvement recommendations. |
| `docs/project-proposal` | Course proposal and planning. |

## Workflow

Start feature and documentation work from `develop`. Open pull requests into
`develop`, then merge completed milestones from `develop` into `main`.
Keep feature branches updated from `develop`. Recreate a feature branch from
`develop` when starting a new task after its previous work has been merged.

## Status

Structure only. Implementation, dependencies, and project content are pending.
