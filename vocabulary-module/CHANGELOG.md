# Vocabulary Module Version History

## Module Contribution

The vocabulary module was designed and developed by **Liu Yudan** for D1-Team10's IELTS Reading Review Assistant project.

## Version 3.0.0 — 30 October 2026

The vocabulary module reached a stable demonstration stage. This version improved input validation, error messages, installation and startup procedures, data-source documentation, and functional limitations. Logic tests and a complete interface workflow test were also completed, making the module ready for demonstration and later integration with the sentence-analysis and mistake-review modules.

## Version 2.0.0 — 21 October 2026

This version expanded the initial recommendation feature into a complete learning workflow. It added offline Chinese definitions from ECDICT, a personal vocabulary notebook, editable definitions, mastered-word filtering, saved passages, and local database storage so that learning records remain available after the application is closed.

## Version 1.0.0 — 16 October 2026

The first version established the core vocabulary-analysis workflow. Users could paste an English passage, and the system could recommend up to 20 learning-priority words using a basic-word list and passage-frequency ranking. It also displayed occurrence counts, source sentences, and clear recommendation reasons.
